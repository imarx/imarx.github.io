Privacy Policy

Last updated: September 29, 2026

What NBV Logger accesses

When you connect a Google account, NBV Logger uses the Google Drive API with read access to file metadata: file and folder names, sizes, folder structure, MD5 checksums, and the email address of the connected account. It does not read or download the content of any file.

How the data is used and stored

This data is used only to show you which of your projects are stored on Google Drive and on your local disks. It is stored only on your own Mac, in the catalog file you choose. The sign-in token is stored in your Mac's Keychain.

Sharing

NBV Logger has no servers. Your data is never sent to the developer or to any third party, and it is not used for advertising or any other purpose.

Changes and deletion

NBV Logger never modifies or deletes files in your Google Drive. To remove its access, revoke it at myaccount.google.com/permissions and delete the catalog file from your Mac.

Google API Services User Data Policy

NBV Logger's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
